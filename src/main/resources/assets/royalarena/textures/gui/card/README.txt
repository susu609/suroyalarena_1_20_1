Card portraits
==============
Put <card id>.png in this folder (or in a resource pack at
assets/royalarena/textures/gui/card/):

  zombie  skeleton_archer  spider  skeletons  big_slime
  stray  vindicator  iron_golem  arrow_storm  fireball  enderman  witch
  creeper  spider_jockey (any card id works)

Any size works; the image is stretched over the card face (31:39), so
124x156 or 248x312 is a good size. A card without a PNG falls back to the spawn
egg of its mob. Press F3+T after adding or changing a file. See docs/UI.md.
